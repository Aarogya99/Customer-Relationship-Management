# Day 23 – System Settings Module

## Implemented

- System settings module structure
- Settings page for CRM configuration
- Store system settings in database
- Update settings functionality
- Load saved settings dynamically

## Features

- Update application name and basic preferences
- Enable or disable selected CRM features
- Persist settings across sessions
- Restrict settings access to admin users only

## Files Affected

- settings/index.php
- SettingsController.php
- Settings model (get and update settings)
