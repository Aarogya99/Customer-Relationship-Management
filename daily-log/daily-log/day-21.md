# Day 21 – Tasks and Follow-up Module

## Implemented

- Tasks module structure
- Create new task functionality
- Store task data in database
- Assign tasks to users
- Task status and priority handling

## Features

- Add task title, description, due date
- Set task priority (Low, Medium, High)
- Set task status (Pending, Completed)
- Timestamp for task creation

- tasks/create.php
- TasksController.php
