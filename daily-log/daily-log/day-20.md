# Day 20 – Deals Pipeline (View and Update)

## Implemented

- Deals listing page
- Fetch deals data from database
- Display deals in pipeline/table view
- Edit deal details

- View deal name, stage, amount, and close date
- Update deal stage (Prospect, Negotiation, Won, Lost)
- Modify deal information
- Redirect after successful update

- deals/index.php
