# Day 19 – Deals / Sales Module

## Implemented

- Deals module structure
- Create new deal functionality
- Store deal data in database
- Link deals with customers or leads

- Add deal name, amount, stage, and close date
- Associate deal with customer or lead
- Default stage set to "Prospect"
- Timestamp for deal creation
