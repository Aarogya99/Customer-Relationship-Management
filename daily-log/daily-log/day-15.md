# Day 15 – Edit Customer (Update Operation)

## Implemented

- Edit customer form
- Pre-filled customer data in edit form
- Update customer details in database
- Server-side validation for update request
- Success and error message handling

## Features

- Update customer name, email, phone, and address
- Prevent update if customer ID is invalid
- Redirect back to customer list after update

## Files Affected

- customers/edit.php
- CustomerController.php
- Customer model (update customer method)
